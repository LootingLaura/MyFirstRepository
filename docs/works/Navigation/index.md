# VoidMap

## 2025

## information


VoidMap ist eine Demo-Version einer Navigations-App.
Die Kernfunktion der Applikation besteht darin, dass die Karte zum Start vollständig von
einem schwarzen Overlay bedeckt ist und einzig durch die Bewegung des getrackten
Gerätestandortes freigelegt werden kann.
Das Overlay besteht aus einem Raster aus Kreisen. Sobald sich ein Nutzer mit dem Gerät in
der Hand fortbewegt, aktualisiert sich sein Standort, welcher durch ein Icon auf der
Nutzeroberfläche erkennbar ist. Alle Kreise, die von dem Icon berührt werden,
verschwinden und legen so die darunterliegende Karte frei.
Die App regt dazu an, die eigene unmittelbare Umgebung zu erkunden und richtet sich
insbesondere an Personen, die Interesse an der Erkundung neuer Städte oder der
Wiederentdeckung vertrauter Umgebungen haben.
